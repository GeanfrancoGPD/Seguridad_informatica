# Virus Watchdog

El virus consiste en ver los cambios sobre archivos que realicemos en el sistema

Para eso usaremos.

- Chokidar: Es el estándar de la industria. Es un "wrapper" que envuelve fs.watch y corrige todos sus errores, asegurando que el monitoreo sea estable y no consuma demasiados recursos de CPU.

```
npm install chokidar
```
